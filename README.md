# firas-bennani.github.io

Animated portfolio (static, no build step).

- `index.html` – the whole site (HTML + CSS + JS)
- `vendor/` – GSAP + ScrollTrigger, Lenis (smooth scroll), Three.js (particle background)
- `Firas_Bennani_CV.pdf` – CV linked from the header and contact section
- `photo.webp` – background-removed portrait used in the hero
- `logos/` – optional: drop `gomycode.png`, `nvidia.png`, `thunders.png` here and they replace the big partner names in the Awards section

Deploy: replace the files in the repo root and push to `main`; GitHub Pages serves it as is.
